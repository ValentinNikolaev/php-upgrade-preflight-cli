# PHP Upgrade Preflight v0.1.0

The first release provides a local, read-only preflight analyzer for Composer-based PHP upgrades, with focused Laravel 7 to Laravel 8/9 intelligence.

## Highlights

- Runs baseline, package-target, dependency, minimal-change, PHP-platform, and staged Composer scenarios in disposable workspaces.
- Reports solver outcomes, structured blockers, package and lock changes, source usage, Laravel findings, staged actions, risk, effort, uncertainty, and linked evidence.
- Emits canonical JSON using report schema `0.6` and a Markdown projection of the same report.
- Provides both `upgrade-intel analyze` and Laravel's `upgrade:analyze` Artisan command.
- Leaves analyzed projects byte-for-byte unchanged; scripts and plugins are disabled for Composer analysis scenarios.

## Release integrity

- Captured Composer output and command diagnostics redact authorization values, credential-bearing and private repository URLs, named secrets, and common provider-token forms before they enter evidence, JSON, Markdown, or console output.
- Synthetic canaries block the release if a secret reaches a report, captured CI stream, checksum set, or decompressed ZIP entry.
- The release gate verifies `SHA256SUMS`, installs all three generated archives in clean Composer projects, runs `upgrade-intel --help`, performs an archive-installed JSON analysis with matching before/after fixture hashes, and boots Laravel package discovery.
- Release automation remains locked to `0.1.x` patch versions until the v0.2.0 release plan is explicitly unlocked.

## Compatibility

The runtime packages require PHP `^8.0`. Clean consumer-install gates cover the core and CLI packages on PHP 8.0, the adapter with Laravel 8/9 on PHP 8.0, Laravel 10 on PHP 8.1, and the declared Laravel 11/12 host integrations on PHP 8.2. The encoded v0.1 upgrade guidance targets Laravel 8 and 9.

See [Installation](https://github.com/ValentinNikolaev/php-upgrade-preflight/blob/v0.1.0/docs/installation.md), [limitations](https://github.com/ValentinNikolaev/php-upgrade-preflight/blob/v0.1.0/docs/limitations.md), and the [schema compatibility policy](https://github.com/ValentinNikolaev/php-upgrade-preflight/blob/v0.1.0/docs/schema.md) before adopting the package in automation.
