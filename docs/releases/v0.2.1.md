# PHP Upgrade Preflight v0.2.1

Released 2026-08-11.

## Purpose

v0.2.1 is the release-hardening patch for the v0.2 line. It preserves schema `0.7`, the PHP `^8.0` runtime floor, Laravel 8–13 host installability, and every supported Laravel transition documented for v0.2.0.

## Fixes

- Windows coverage verification canonicalizes equivalent filesystem paths while continuing to reject stale or incomplete coverage data.
- Release-archive Composer repositories are encoded safely on Windows, and the Windows Laravel archive consumer explicitly provisions `ext-fileinfo`.
- Package test sources use redaction specimens that are independent from the release verifier's seeded canaries, and the complete package source surface is checked for those canaries.
- The published quick start verifies that Core, CLI, and Laravel resolve to the exact source and distribution commits behind their GitHub-verified signed tags. A matching version string alone is not sufficient.

## Upgrade

The existing v0.2 constraints select this patch automatically:

```bash
composer update php-upgrade-preflight/core php-upgrade-preflight/cli php-upgrade-preflight/laravel --with-all-dependencies
```

New installations remain:

```bash
composer require php-upgrade-preflight/cli:^0.2 php-upgrade-preflight/laravel:^0.2
```

No report-schema migration is required from v0.2.0. Consumers upgrading from v0.1 must still follow the schema `0.6` to `0.7` migration in the [schema guide](../schema.md).

## Release integrity

Publication requires verified signed `v0.2.1` tags in the monorepo and all three distribution repositories, exact distribution payload matches, the PHP 8.0–8.5 and Windows deterministic gates, normal and lowest Laravel 8–13 installs, Linux and Windows fresh-clone and archive consumers, checksum-bound archives, dependency inventory, artifact provenance, synthetic-secret scans, exact Packagist source/dist references, and an immutable-target published quick start.
